# 博客标签规范

适用范围：`src/content/posts/` 内文章与草稿的 frontmatter `tags` 字段。

## 写法

- 使用行内数组，例如 `tags: [深度学习, 心电图, 对比学习]`。
- 一篇文章通常选 2–4 个标签；个人随笔等主题简单的文章可只用 1 个。
- 顺序为：核心领域 → 应用对象 → 具体方法或文章类型。
- 优先复用已有标签；仅在正文实质讨论该主题时添加，避免将所有提到的模型名都列为标签。
- 使用中文主题名称，保留 Markdown、Fuwari、Transformer 等通行专名及大小写。
- `category` 用于所属栏目，`tags` 用于跨栏目关联文章，两者不必相同。

## 推荐词表

| 标签 | 使用场景 |
| --- | --- |
| 深度学习 | 神经网络原理、训练方法或以深度模型为核心的研究 |
| 心电图 | ECG 信号、心电分类、去伪影及其应用 |
| 信号处理 | 滤波、去噪、信号表示与预处理 |
| 数字滤波 | FIR、IIR、带通、陷波等方法 |
| 伪影去除 | 专门讨论伪影来源、识别与处理的文章 |
| 神经网络 | 网络结构与训练基础 |
| Transformer | 以注意力机制或 Transformer 为重要内容的文章 |
| 对比学习 | 正负样本、对比损失、表示学习方法 |
| 自监督学习 | 以自监督训练为重要内容的文章 |
| 论文精读 | 围绕具体论文或综述进行阅读、分析与复习 |
| 个人随笔 | 自我介绍、生活与个人思考 |
| 博客搭建 | 建站、写作工具、主题配置与文章格式 |
| Markdown | Markdown 语法与排版；不是所有 Markdown 文件都需要此标签 |
| Fuwari | Fuwari 主题使用与配置 |
| 视频 | 视频嵌入或视频功能；仅引用教学视频不必添加 |
| 示例 | 模板演示文章，统一替代 Demo、Example |

## 旧标签如何处理

| 原写法 | 统一方式 |
| --- | --- |
| ECG | 心电图 |
| Blogging、Customization | 博客搭建（文章内容相关时） |
| Demo、Example | 示例 |
| Video | 视频 |
| personal | 个人随笔（个人内容）；技术笔记按实际主题重新标注 |
| base | 删除，改为实际领域或方法，例如信号处理、数字滤波 |
| 人工智能、医学AI | 当前相关文章使用更具体的深度学习、心电图；这些词并非严格同义词 |
| 文献阅读 | 当前论文分析类文章统一使用论文精读 |
| CLOCS、ICA、嵌入空间等细分词 | 保留在正文，标签优先使用对比学习、信号处理等可复用主题 |

以后若出现真正独立的新主题，可以扩展词表；不要只因中英文写法不同而新建标签。
